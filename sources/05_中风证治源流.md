# 中风证治源流

## 源流概述

中风、半身不遂属中医"中风""偏枯""卒中"范畴。

## 历史沿革

- **《内经》**："大厥""薄厥"，"血之与气，并走于上，则为大厥"
- **《金匮要略》**：立中风专篇，分中经中络中脏中腑
- **《医学衷中参西录》**：张锡纯创镇肝熄风汤

## 现代名家经验

- **杨百萬**：通脉汤，益气活血通络
- **李仲愚**：乌附星香汤，温经通络化痰
- **张学文**：通脉舒络汤，活血舒筋通络
- **李可**：补阳还五汤加减，破格救心汤

## 核心治法

1. 平肝熄风（急性期）
2. 益气活血（恢复期）
3. 化痰通络（后遗症）
4. 补肾固本（康复期）
