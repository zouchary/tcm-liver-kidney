# 男性泌尿生殖证治源流

## 源流概述

男性不育、阳痿、前列腺炎等属中医"阳痿""不育""精浊""癃闭"范畴。

## 历史沿革

- **《内经》**："肾者，作强之官，伎巧出焉"
- **《诸病源候论》**："肾虚不能荣于阴器，故痿弱"
- **《景岳全书》**："阳痿"篇，认为"火衰者十居七八，火盛者仅有之耳"
- **《傅青主男科》**：重视心肾不交

## 现代名家经验

- **罗元恺**：温肾益精汤
- **李培生**：十子育麟汤
- **谢海洲**：韭子五子丸
- **邓铁涛**：邓氏通淋汤
- **印会河**：疏肝散结汤、前列康复散
- **张锡君**：双虎通关丸

## 核心治法

1. 温肾壮阳（阳痿）
2. 补肾益精（不育）
3. 清热利湿（前列腺炎）
4. 软坚散结（前列腺增生）
