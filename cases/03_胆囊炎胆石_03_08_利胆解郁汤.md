# 利胆解郁汤

**来源**：任继学

## 主治
适用于慢性胆胀病。症见胆区疼痛，并向右肩背放射，纳呆口苦，胁痛腹胀，舌质红，苔薄黄，脉弦滑而数者。

## 组成
```
柴胡15克 茵陈50克 马齿苋15克 元胡15克 银花15克 川楝子15克
```

## 功能
疏肝理气，利胆解郁。

## 用法
水煎服，日服2次，早饭前，晚饭后30分钟温服。服药期间，停服一切与本病有关的中西药物。

## 方解
方中柴胡、川楝疏肝理气止痛；茜陈清利湿热；银花、马齿苋清热解毒；元胡理气活血止痛。诸药合用，共奏疏利肝胆、理气止痛之功。

## 加减
偏少阳证加黄芩15克、胆草15克、清半夏10克，水煎服，并同服紫金锭；偏湿热加木通15克、滑石75克、郁金30克、青皮15克，水煎服，并送服紫金锭一锭；见胆郁证者，减银花加砂仁壳10克、香橼15克，水煎服。

## 按语
本方虽为慢性胆胀病而设，但从组成来看仍为一首祛邪之剂，故病虽为慢性，但证当属实，对于虚证胆胀，则不宜之。
