## 核心内容

### 八证型辨证体系

| 证型 | 主症 | 病机 | 主方 |
|------|------|------|------|
| 1. 肝郁气滞 | 胁肋胀痛、情志抑郁、善太息 | 肝失疏泄，气机郁滞 | 柴胡疏肝散 |
| 2. 肝胆湿热 | 胁痛如灼、口苦、苔黄腻 | 湿热蕴结肝胆 | 龙胆泻肝汤 |
| 3. 肝阴不足 | 胁肋隐痛、舌红少苔 | 阴血不足，肝失濡养 | 一贯煎 |
| 4. 肾阳虚 | 腰膝酸软、畏寒、阳痿 | 肾阳不足，温煦失职 | 肾四味 / 右归丸 |
| 5. 肾阴虚 | 腰膝酸软、潮热盗汗 | 肾阴亏损，虚火内扰 | 六味地黄丸 |
| 6. 脾肾阳虚 | 浮肿、腰以下为甚、尿少 | 脾阳不运，肾失气化 | 真武汤 / 实脾饮 |
| 7. 瘀血内阻 | 胁痛固定、面色黧黑、舌暗瘀斑 | 瘀血阻滞，络脉不通 | 血府逐瘀汤类 |
| 8. 痰湿蕴结 | 体胖痰多、苔白腻、脘腹胀满 | 痰湿内蕴，气机阻滞 | 二陈汤 / 平胃散 |

### 常见问题速查（12 组）

肝郁气滞、肝胆湿热、肝阴不足、肾阳虚、肾阴虚、脾肾阳虚水肿、水臌、阳痿、阳黄、阴黄、中风后遗症气虚血瘀、脱证回阳 —— 每组给出症状组合、证型、主方与要点。

### 李可体系整合（`like-liver-kidney.md`）

**肾四味** —— 枸杞子、菟丝子、仙灵脾、补骨脂各 30–60g，平补肾中阴阳，不偏不倚，为各类肾虚证之基础方。

**腰痛三型论治**
- 肾虚腰痛（最常见）：肾四味打底，阳虚加肉桂附子（右归丸意），阴虚加熟地山萸肉（左归丸意）
- 寒湿腰痛：麻黄附子细辛汤合肾着汤
- 瘀血腰痛：活络效灵丹加土元、全蝎、蜈蚣

**水肿 —— 大气下陷理论**：不囿于利水常法，脾肾阳虚合大气下陷，以真武汤合肾四味加黄芪。

**阳痿 —— 从肝论治**：肝气郁结、阳气不达者，以四逆散合肾四味，非一味补肾。

**破格救心汤 —— 脱证急救**：附子 30–100g 先煎 2h，麝香 0.3–0.5g 冲服。**急救方，非一般调理方。**

**补阳还五汤 —— 中风后遗症**：黄芪 60–120g 起逐步加量，加肾四味固本。

### 附子剂量安全规范（李可经验）

| 病情 | 起始量 | 最大量 | 煎法 |
|------|--------|--------|------|
| 普通阳虚 | 30g | 60g | 文火 2h |
| 重症阳虚 | 45g | 90g | 文火 2h |
| 亡阳急救 | 60g | 200g | 武火 1h+ |
| 肾四味平补 | — | — | 不需先煎 |

- 附子须逐步加量（每日叠加 10g），观察瞑眩反应
- 炙甘草用量为附子 1/2~等量，配干姜可监制毒性
- **煎煮不充分（<1h）为主要中毒原因**

## 使用方式

### 导入 AI Agent 技能库

将 `SKILL.md` 放入技能库目录，Agent 会依据 frontmatter 中的 `description` 自动匹配触发条件（用户自述胁痛/腰痛/水肿/阳痿/黄疸/腹胀等肝肾相关症状时触发）。

### 典型工作流

```
用户自述症状
  → 决策路由树（辨肝郁/湿热/肝阴 → 辨肾虚 → 辨水湿/痰湿 → 辨瘀血 → 辨脱证）
    → 八证型归属 + 病机
      → 查 modules/ 取方剂组成与加减
        → 查 cases/ 找相似医案
          → 查 like-liver-kidney.md 取李可经验方与附子规范
            → 按 SKILL.md「五、输出格式」输出
```

### 输出结构

证型 → 症结所在 → 中药内服（方名/来源文献/组成/功效/用法）→ 针灸配穴 → 生活调摄 → 注意事项。

## ⚠️ 重要提示

本仓库为中医学习与知识工程参考，**不构成医疗建议**。

- **附子、破格救心汤**等峻剂**必须**在有经验中医师指导下使用
- 破格救心汤为急救方，附子最大量 200g 属经验上限，非一般调理用量
- 水蛭、虻虫、全蝎、蜈蚣等破血搜风毒烈之品，须专业医师辨证掌握
- 症状严重或持续，建议线下就医
- 孕妇、儿童、老年人用药须特别注明并建议咨询专业医师
- 本仓库内容依据公开文献整理，实际应用请以执业医师面诊为准
